# Mac Mini Cluster Architecture

> **Track:** OpenClaw Real-World Lab Build (Track 3)
> **Course 1 of 5**

Design the network topology, storage layout, and redundancy strategy for a production Mac Mini cluster.

---

## Modules

### Module 1: Network Topology for Mac Mini Clusters

**Learning Objectives:**
- Design a flat LAN vs. VLAN topology
- Configure static IPs for all nodes
- Document network diagram and addressing scheme

### Module 2: Storage Configuration & Shared Filesystems

**Learning Objectives:**
- Mount NFS shares across all nodes
- Configure Time Machine for node backups
- Benchmark read/write speeds across nodes

### Module 3: Power & Heat Management at Scale

**Learning Objectives:**
- Calculate total power draw for 6 nodes
- Implement smart PDU monitoring
- Configure thermal alerts

### Module 4: Redundancy & Failover Design

**Learning Objectives:**
- Identify single points of failure
- Implement node health checks
- Document failover runbook
